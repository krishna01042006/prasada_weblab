WEB PROGRAMMING LAB ASSIGNMENT
Personal Resume and Bio-data Website

FILES:
index.html       - Home page
resume.html      - Resume page
biodata.html     - Bio-data page
contact.html     - Contact form page
css/style.css    - Common CSS styling
js/script.js     - Simple JavaScript and jQuery

HOW TO RUN:
1. Extract the ZIP file.
2. Open the folder.
3. Double-click index.html to open it in a browser.
4. Use the navigation links to visit other pages.

BEFORE SUBMISSION:
- Personal details, education years and email have been filled in. Review them before submission.
- Check that all personal information is correct.
- The contact form is only a demonstration. It does not send or store data.

NETLIFY HOSTING:
1. Visit https://app.netlify.com/ and sign in.
2. Choose Add new site, then Deploy manually.
3. Drag the extracted project folder (the folder containing index.html) into the upload area.
4. Wait for deployment. Netlify will provide a public website URL.
5. Open the URL and test all pages.

CODE EXPLANATION:
- HTML creates the content and links between pages.
- CSS controls colours, spacing, tables, forms and page layout.
- JavaScript checks the contact form.
- jQuery is used for the document-ready event, click effect and slideToggle().

DESIGN UPDATE:
The website uses a simple grey and teal colour theme, with a gradient header, highlighted navigation links, content cards and subtle shadows.

PROFILE PHOTO:
Circular profile photo is used on Home, Resume and Bio-data pages. Keep assets/prasada-photo.png in the assets folder when deploying.

RESUME TECHNICAL SKILLS:
Python, JavaScript, Flutter, HTML and CSS.
